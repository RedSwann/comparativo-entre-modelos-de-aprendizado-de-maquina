Como será realizado o experimento?

Para comparar os três modelos, utilizaremos o conjunto de dados NSL-KDD.

O que é NSL-KDD? ⌄

O NSL-KDD O NSL-KDD é um conjunto de dados muito utilizado em pesquisas e testes de aprendizado de máquina para a detecção de invasões em redes de computadores.

Ele contém registros de conexões classificados como tráfego normal ou ataques, com características como protocolo, serviço utilizado e quantidade de dados transmitidos. Por que utilizá-lo?.

Por que utilizá-lo?

Neste experimento, utilizaremos o NSL-KDD para treinar e avaliar os três modelos: Árvore de Decisão, Random Forest e XGBoost. O objetivo é ensinar os algoritmos a distinguir conexões normais de possíveis ataques e comparar seus desempenhos utilizando os mesmos dados.
